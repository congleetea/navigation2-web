# Nav2 全局规划实验室

中文、浏览器本地计算的六模式教学动画。与真实 Nav2 实现的差异在页面各算法说明中列出；不连接 ROS、不发送地图数据。

## 打开

直接用浏览器打开 `dist/index.html` 即可，所有脚本和样式均来自本地，不需要安装依赖。也可运行：

```sh
python3 -m http.server 8765 --directory web/nav2-planner-lab/dist
```

从工作区根目录执行后，访问 `http://localhost:8765`。

## 操作

1. 选择算法、地图场景。
2. 点击「S 起点」或「G 目标」，再点击空闲格子；也可输入坐标。
3. 位姿算法可调朝向，Lattice 使用 45° 档位；屏幕 y 轴向下，正角度顺时针。
4. 用「障碍」「擦除」点击或拖动编辑地图。
5. 点击开始探索、前后单步，或拖动时间线。阶段按钮可直接跳转。
6. 选择「查看」点击格子，读取地图代价及当前势值/累计代价。
7. 修改地图、端点、权重或朝向会清除旧结果；切换算法保留地图和位置。

键盘：非输入控件聚焦时，空格播放/暂停，左右箭头前后单步。

## 文件

- `dist/engine.js`：纯计算引擎与事件生成，兼容浏览器和 Node。
- `dist/app.js`：交互、时间线回放、Canvas 渲染。
- `dist/index.html` / `style.css`：页面结构与响应式布局。
- `tests/engine.test.cjs`：搜索与事件回放数据回归检查。

运行测试（Node 18+）：

```sh
node --test web/nav2-planner-lab/tests/*.test.cjs
```

已使用本机 Chrome 检查六种算法完成、时间线往返一致、地图点击、单步、播放暂停、390px 布局与浏览器异常。算法动画按预计算的事件序列回放，并不是每按一次按钮才调用一次真实 Nav2。

## 教学简化

- NavFn 使用四邻域二次近似势更新和负梯度提取，但以最小堆替代原始缓冲区，简化代价映射与回退。
- Theta* 展示祖先 LOS 重连，采用保守线段碰撞检查，保留末端位置。
- Smac 2D 使用八邻域，至少 12 个点才执行位置平滑；短路径也会独立计算有效朝向。
- Hybrid 为前进型曲率模型，16 朝向档位；未实现倒车、障碍启发表、解析连接和后续平滑。
- Lattice 使用 8 朝向内置教学动作表（含原地旋转），并非官方 JSON 运动基元；不保证曲率连续。
- 位姿规划使用半径 0.32 格圆形足迹与近似目标容差；所有性能数字仅用于本网页观察。

## 格内数值与色标

默认搜索阶段显示 f（NavFn A* 为 P+h，其他 A* 为 g+h），NavFn Dijkstra 显示 P，NavFn 梯度提取阶段自动切回 P。可手动切换 f、g/P、h 和地图局部代价 C。颜色从蓝（低）经青、黄过渡到橙红（高）；搜索数值的色标上限由本轮预计算事件确定，整轮回放不变。未计算为 ∞、障碍为 ×，数值默认保留一位小数，观察器提供三位小数。

黄色边框表示当前步骤实际改变数值的格子，下方显示旧值到新值。Hybrid/Lattice 每格取已发现状态中 f 最小的代表位姿，显示同一位姿的 g、h、f，不代表同格所有朝向代价相同。地图较窄时可触摸横向滚动；点击设置位置，滑动不会修改起终点。绘制/擦除模式的拖动用于编辑。

真实 Nav2 内部值：自由0，分级代价1–252，内切膨胀253，障碍254，未知255。本教学膨胀上限180且未模拟253/255；详情见网页新增说明表。
